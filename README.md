# General Market Regime & Direction Forecasting Engine

A Python research project that detects market regimes and estimates 
the probability that any index closes up tomorrow — for any ticker.

## What it does
- Detects Bull / Sideways / Bear regimes using a Hidden Markov Model
- Forecasts next-day direction using logistic regression
- Works on any ticker: Nifty, S&P 500, Bank Nifty, Gold, any index

## Built with
Python · pandas · hmmlearn · scikit-learn · Streamlit
